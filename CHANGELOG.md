# Changelog

## v0.4.0 — first GitHub release

Published October 29, 2026. The owner confirmed this version working before publication; the installer ZIP is unchanged from that tested package.

- Adds automatic full, non-draining UV for the local player across Easy, Normal, Hard and Nightmare in solo/host sessions.
- Handles the native Nightmare battery charge state and charge resets.
- Adds UV diagnostics to the existing report export.
- Preserves the v0.3.1 VR freeze combination, right-only no-clip, normal left-click run, mapped flight controls and keyboard controls.

## Earlier delivered versions

These versions preceded GitHub publication and are listed for upgrade context; they are not separate GitHub releases.

- **v0.3.1:** both thumbstick clicks toggle freeze; right-only release toggles no-clip; left click remains the normal run input.
- **v0.3.0:** VR shortcuts and mapped joystick flight, jump/rise and crouch/descend controls.
- **v0.1.0 through v0.2.2:** freeze and no-clip development. Their known payload fingerprints remain supported by the updater.
